# Lawyer Assignment Policy

## Purpose
Defines the rules for assigning lawyers to accepted cases.

## Assignment Rules

A lawyer can be assigned only if:

- Status is **Active**.
- Current caseload is below the maximum limit.
- Seniority meets the case requirements.
- Specialization matches the case type.

## Authorization

- Only **Senior Associates** and **Partners** can assign lawyers.
- Receptionists can view assignments but cannot create or modify them.

## Multiple Assignments

- A case may have more than one lawyer.
- Only one lawyer can have the **Lead** role.
- Additional lawyers must be assigned as **Support**.
